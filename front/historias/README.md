# Histórias dos Reinos

Coloque aqui um arquivo `.md` por reino, com o nome do reino como nome do arquivo (ex.: `Rushoko.md`, `Galte.md`).
O botão "História" na aba Reinos do front carrega o conteúdo do arquivo correspondente.

Por enquanto os arquivos contêm apenas a raça do reino; as histórias completas podem ser preenchidas depois.
